# 易卦占卜网站

一个融合中国传统文化与现代交互设计的八卦占卜网站，采用易经理论和五行学说提供智能占卜解读。

## 📋 项目概述

**易卦占卜**是一个纯前端的交互式占卜应用，基于中国古代易经的八卦系统，为用户提供人生运势的占卜和指引。通过现代化的 Web 设计和流畅的交互动画，将传统文化与当代审美完美融合。

### ✨ 核心特性

- **8卦系统**：采用中国易经的八卦（乾、坤、震、巽、坎、离、艮、兑）进行占卜
- **5卦布局**：按五行方位分布（东木、南火、中土、西金、北水）
- **智能解读**：基于易经理论和五行生克关系生成占卜结果
- **流畅动画**：卦象旋转、太极呼吸等视觉效果
- **水墨风格**：传统中国文化主题的视觉设计
- **响应式布局**：完美支持桌面、平板、手机等各种设备
- **纯前端实现**：无需后端服务，可直接在浏览器运行

## 🚀 快速开始

### 1. 打开网站

```bash
# 使用浏览器打开 index.html
file:///path/to/ai-diviner/index.html
```

### 2. 进行占卜

1. 在左侧输入框输入你想了解的问题（如「我最近的事业运如何？」）
2. 点击「开始占卜」按钮
3. 观看中间的5个卦象旋转动画
4. 在右侧查看详细的占卜解读结果
5. 点击「重新占卜」可以进行下一次占卜

## 💡 占卜原理

### 8卦含义

| 卦象 | 符号 | 名称 | 五行 | 传统含义 |
|------|------|------|------|----------|
| ☰ | 乾 | 天 | 金 | 创始、强劲、刚健 |
| ☷ | 坤 | 地 | 土 | 承载、柔顺、包容 |
| ☳ | 震 | 雷 | 木 | 振动、启蒙、新生 |
| ☴ | 巽 | 风 | 木 | 柔和、渗透、顺应 |
| ☵ | 坎 | 水 | 水 | 流动、智慧、险阻 |
| ☲ | 离 | 火 | 火 | 光明、热烈、粘着 |
| ☶ | 艮 | 山 | 土 | 停止、沉静、思考 |
| ☱ | 兑 | 泽 | 金 | 喜悦、沼泽、交流 |

### 五行生克

```
相生关系：木→火→土→金→水→木
相克关系：木克土、土克水、水克火、火克金、金克木
```

### 解读逻辑

占卜结果基于以下多个维度综合分析：

1. **各卦单独含义**：根据抽中的卦象的正位寓意
2. **五行生克分析**：分析各卦间的五行关系
3. **问题针对性**：根据问题类型（事业、感情、财运等）生成相关建议
4. **整体格局**：综合考虑所有卦象的组合寓意
5. **易经智慧**：融入古代智慧，给予人生指引
